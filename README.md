# CS3090_block_project2

The purpose of this project, ServiceBay, is to increase communication between a client and an auto shop in a project management application. This is an all-in-one app that local auto shop may use to track process on vehicles, order parts and send live updates to clients to reference as a digital service record. All vehicle information and services are available to look up, manage and update accordingly for all employees of a shop. Transparency is made easier with this direct line of communication provided between the client and the people working directly on their car with live tracking and time estimation. Auto shop culture and atmospheres will increase with the use of this app by increased organization making customers a part of the process from start to finish.
